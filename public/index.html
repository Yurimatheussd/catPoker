Como funciona o cálculo do Cat Poker?

  1. Cada participante atribui notas de 0 a 5 para cinco critérios: complexidade técnica, esforço, incerteza, dependências e risco.
  2. O sistema soma as cinco notas, divide por cinco e arredonda a média para o inteiro mais próximo.
  3. Calcula a média das notas individuais arredondadas dos participantes.
  4. Converte essa média para uma das pontuações Fibonacci: 1, 2, 3, 5, 8 ou 13.
  5. O gráfico apresenta a média das notas de cada critério, ajudando a entender onde a equipe percebe maior dificuldade. Ele não entra no cálculo dos pontos.
🐾 Exemplo

Uma pessoa deu as notas 5, 4, 1, 1 e 2. Média = 13 / 5 = 2,6 → média arredondada 3.

Cinco participantes tiveram médias arredondadas 4, 4, 4, 3 e 4.

Média = (4 + 4 + 4 + 3 + 4) / 5 = 3,8.

Resultado Fibonacci = 8 pontos.
